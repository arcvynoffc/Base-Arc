# Arcvyn

Simple WhatsApp Bot built with **Node.js** and **Baileys**.

## Features

* Case-based command handler
* Multi-file authentication
* Public & Self mode
* Owner commands
* Interactive messages
* Lightweight and easy to customize

## Installation

```bash
git clone https://github.com/arcvynoffc/REPOSITORY.git
cd REPOSITORY
npm install
```

## Start

```bash
npm start
```

## Configuration

Edit the settings in:

```text
Arc/settings.js
```

Configure:

* Owner Number
* Bot Name
* Owner Name
* Other bot settings

## Requirements

* Node.js 20+
* npm
* Stable internet connection
